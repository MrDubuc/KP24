Connect Google Calendar

This dashboard uses read-only access. Google asks you to create a free web credential once, then you can connect your calendar from this screen.

  1. Open Google Cloud and enable the Google Calendar API.
  2. Create an OAuth client ID with the application type set to Web application.
  3. Add the exact address below under Authorized JavaScript origins.
  4. Paste the client ID Google gives you into the last field.

The client ID identifies this webpage; it is not your password or a client secret.

Calendar events stay in this browser tab. The access token is kept only in memory and is discarded when you close or reload the page.
